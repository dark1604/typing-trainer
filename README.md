# Keyris — Тетріс-тренажер швидкого друку

Інтерактивний браузерний тренажер швидкого друку для учнів **4–9 класів** у стилі неонового тетрісу. Створений для уроків інформатики та самостійної практики сліпого друку.

## Основні можливості

- **4 режими роботи:**
  - **Літери** (4–5 клас) — окремі літери для вивчення розташування клавіш (без рідкісної `ґ`).
  - **Слова** (6–7 клас) — словник із **1018 унікальних українських слів** (термінологія інформатики 4–9 класів + загальна лексика) та **60+ англійських IT-термінів**.
  - **Код** (8–9 клас) — короткі конструкції Python, JS, HTML та CSS.
  - **⏱ Тест 60с** — хвилинний замір швидкості з прискоренням кожні 5 блоків та визначенням рівня (`Новачок`, `Упевнений користувач`, `Швидкий друкар`, `Кібер-майстер`).
- **Тетріс-механіка:**
  - Пропущені блоки осідають на дні у вигляді каменів; серія з **10 правильних блоків поспіль** спалює нижній ряд.
  - Спецблоки: `❄️ Заморозка часу (4с)` та `⚡ Метеор (2x балів)`.
- **Навчальні підказки:**
  - Віртуальна клавіатура з **кольоровими зонами пальців** та підсвіткою наступної клавіші (можна приховати).
  - Автоматичні індикатори неправильної розкладки (`UA`/`EN`) та увімкненого `Caps Lock`.
  - Список «клавіш-пасток» (де було найбільше помилок) на екрані завершення.
- **Зручність для класу:**
  - Нульовий поріг входу (без реєстрації), окремі рекорди для кожного режиму в `localStorage`.
  - Темна та світла теми, синтезовані звуки (Web Audio API) з кнопкою вимкнення звуку.
  - Адаптація під різні монітори ПК/ноутбуків та автоматичне блокування запуску з телефонів і планшетів.

## Публікація на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `typing-trainer`).
2. Прив'яжіть локальний репозиторій та відправте код:
   ```bash
   git remote add origin https://github.com/dark1604/typing-trainer.git
   git push -u origin main
   ```
3. У налаштуваннях репозиторію перейдіть до **Settings → Pages**, оберіть гілку `main` та папку `/ (root)` і натисніть **Save**.
4. Через 1–2 хвилини тренажер буде доступний за посиланням `https://dark1604.github.io/typing-trainer/`.
